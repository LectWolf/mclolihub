# 鹈鹕 HTML 生成检测

质量检测只发送一次流式 HTML 生成请求，固定使用 Chat Completions。账号配置的 Responses 或 adaptive 协议不改变此检测使用的端点。仅支持可调用 Chat Completions 的 API Key 账号；OAuth 账号明确返回不支持，不回退到 Responses。

读取完整流，收到 `[DONE]` 后结束；兼容上游发送非空 `finish_reason` 后正常关闭连接。无需 `response.completed`，不限定 `finish_reason` 为 `stop`。首个文本片段和 HTML 闭合标签都不会提前终止流。

流异常断开、读取失败、无效流、上游 429 或 5xx 最多重试 5 次，即首次请求加 5 次重试，最多 6 次。重试使用指数退避，整个生成过程仍受 900 秒预算及父请求取消控制。每次重试都是独立生成，使用该次响应，不拼接前一次的部分 HTML。认证失败、参数错误、输出超限及正常结束但缺少完整 HTML 不重试。

流正常结束后提取完整 HTML，保存作品及原始输出，并标记生成成功。HTML 源码评分、视觉审查请求、分数通过线均已移除；不再发起第二次评分请求。

数据库中的评分列保留兼容历史记录，新结果分数为 `null`。读取历史记录时保留已存状态和原因，不按分数重新判定。每组最多保留 5 条历史，HTML 和原始输出按需读取。

HTML 预览继续使用净化后的 sandbox iframe，禁止脚本和外部网络；原始模型输出以纯文本展示。
